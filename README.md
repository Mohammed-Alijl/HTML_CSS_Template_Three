# Template Three - Modern Landing Page

A modern, responsive landing page template built with HTML5 and CSS3.

## Features

- Fully responsive design
- Clean and modern UI
- Multiple sections including:
  - Articles
  - Gallery
  - Features
  - Testimonials
  - Team Members
  - Services
  - Events
  - Top Videos
  - Pricing Plans
  - Contact Form

## Setup Instructions

1. Clone the repository
2. Open `index.html` in your web browser
3. No additional setup required

## Customization

### Colors
The template uses a color scheme that can be customized in `assets/css/master.css`. Look for the `:root` selector at the top of the file to modify the color variables.

### Content
All content can be modified directly in the `index.html` file. Each section is clearly marked with comments and has its own container.

### Images
Replace images in the `assets/img` directory with your own images. Ensure they match the required dimensions:
- Logo: 150x150 pixels
- Team Member Photos: 300x300 pixels
- Gallery Images: 400x300 pixels
